# Tile Master 3D

Game Tile Master 3D (dựng lại từ bản 1.12.9) gồm hai phần nằm cùng cấp:

| Thư mục | Nội dung | Đọc trước |
|---|---|---|
| `client/` | Project Unity 6000.3.10f1 (mở thư mục này trong Unity Hub) | `HANDOFF.md`, `CLAUDE.md` |
| `server/` | Server game (chưa làm; kế hoạch ở `HANDOFF.md` mục 8) | `server/README.md` |

Tài liệu chung ở gốc: `HANDOFF.md` (trạng thái, kế hoạch), `CLAUDE.md`, `docs/` (quy trình, giao thức mạng `docs/net_protocol.md`, việc để sau), `Tools/` (công cụ dịch ngược), `videos/` (video so sánh trên máy).

Lịch sử: trước 2026-11-20 project Unity nằm thẳng ở gốc `TileMaster3D/`.
